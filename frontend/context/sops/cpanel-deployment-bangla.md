## 📥 ধাপ ১ — GitHub থেকে আপডেট ফাইল ডাউনলোড

> **কেন:** GitHub-এ কোড পুশ হলে সার্ভার অটোমেটিক ওয়েবসাইটের একটি রেডি-টু-ডেপ্লয় জিপ ফাইল বানিয়ে রাখে। আপনাকে শুধু সেটা নামাতে হবে।

**করণীয়:**

১. ব্রাউজারে GitHub রিপোজিটরিতে যান।
২. উপরের মেনু থেকে **Actions** ট্যাবে ক্লিক করুন।
৩. তালিকায় সবার উপরে যেটিতে **সবুজ টিক ✅** আছে, সেটিতে ক্লিক করুন।
৪. পেজের একদম নিচে স্ক্রল করুন — **Artifacts** সেকশন দেখতে পাবেন।
৫. নিচের নামের ফাইলটিতে ক্লিক করুন:
```
deploy_cpanel
```
> **ফলাফল:** `deploy_cpanel.zip` নামে একটি ফাইল আপনার কম্পিউটারে ডাউনলোড হবে।

## 🧹 ধাপ ২ — সার্ভার থেকে পুরনো ক্যাশ ফাইল মোছা

> **কেন:** পুরনো ক্যাশ থাকলে নতুন আপডেট ঠিকমতো কাজ করবে না — পুরনো ডিজাইন বা ভাঙা পেজ দেখাতে পারে।

> [!CAUTION]
> **শুধুমাত্র** নিচে বলা ২টি ফোল্ডার ডিলিট করবেন। অন্য কিছু ডিলিট করলে ওয়েবসাইট ভেঙে যাবে।

**করণীয়:**

১. cPanel-এ লগইন করুন → **File Manager** খুলুন।

২. বাম পাশের ফোল্ডার ট্রি থেকে এই ফোল্ডারটিতে ক্লিক করুন:
```
cib_nextjs_app
```

৩. ডানপাশের ফাইল লিস্টে **`.next`** নামের ফোল্ডারটি খুঁজুন।

৪. `.next` ফোল্ডারের ওপর **রাইট-ক্লিক** → **Delete** → ✅ `Skip the trash and permanently delete` বক্সে টিক দিন → **Confirm**।

৫. এবার বাম পাশ থেকে এই ফোল্ডারে যান:
```
public_html
```

৬. ডানপাশ থেকে **`_next`** নামের ফোল্ডারটি খুঁজুন।

৭. `_next` ফোল্ডারের ওপর **রাইট-ক্লিক** → **Delete** → ✅ টিক দিন → **Confirm**।

> **ফলাফল:** দুটি পুরনো ক্যাশ ফোল্ডার মুছে গেছে। সার্ভার এখন নতুন ফাইল নেওয়ার জন্য প্রস্তুত।

---

## 📤 ধাপ ৩ — নতুন ফাইল আপলোড ও এক্সট্র্যাক্ট

> **কেন:** ধাপ ১-এ ডাউনলোড করা জিপ ফাইলটি এখন সার্ভারে তুলতে হবে এবং আনজিপ করতে হবে।

**করণীয়:**

১. বাম পাশ থেকে আবার এই ফোল্ডারে ক্লিক করুন:
```
cib_nextjs_app
```

২. উপরের টুলবার থেকে **+ Folder** বাটনে ক্লিক করুন।

৩. নতুন ফোল্ডারের নাম হিসেবে হুবহু এটি লিখুন:
```
update
```
**Create New Folder** চাপুন।

৪. নতুন তৈরি হওয়া `update` ফোল্ডারে **ডাবল-ক্লিক** করে ভেতরে ঢুকুন।

৫. উপরের টুলবার থেকে **Upload** বাটনে ক্লিক করুন।

৬. **Select File** চাপুন → আপনার কম্পিউটার থেকে `deploy_cpanel.zip` ফাইলটি সিলেক্ট করুন।

৭. প্রগ্রেস বার **100% সবুজ** হওয়া পর্যন্ত অপেক্ষা করুন → তারপর নিচে `Go Back to ...` লিংকে ক্লিক করে ফিরে আসুন।

৮. এখন `deploy_cpanel.zip` ফাইলের ওপর **রাইট-ক্লিক** → **Extract** → পপআপে **Extract Files** বাটনে ক্লিক → **Close** চাপুন।

> **ফলাফল:** `update` ফোল্ডারের ভেতরে `.next`, `content`, `node_modules`, `public`, `package.json`, `server.js` — এই ফাইল ও ফোল্ডারগুলো দেখা যাবে।

## 🚚 ধাপ ৪ — ফাইলগুলো সঠিক জায়গায় বসানো

> **কেন:** এক্সট্র্যাক্ট করা ফাইলগুলো এখন `update` ফোল্ডারে আছে, কিন্তু ওয়েবসাইট চালাতে হলে এগুলো নির্দিষ্ট জায়গায় রাখতে হবে।

> [!IMPORTANT]
> এই ধাপে **Move** করার সময় যে পাথ (Path) দিতে হবে, সেটি নিচের কোড ব্লক থেকে **কপি** করে পপআপ বক্সে **পেস্ট** করবেন। হাতে টাইপ করবেন না — একটু ভুল হলেই ফাইল হারিয়ে যেতে পারে।

### অংশ ক: ডিজাইন ফাইল (ছবি, ফন্ট ইত্যাদি) সরানো

১. `update` ফোল্ডারের ভেতর থেকে **`public`** ফোল্ডারে **ডাবল-ক্লিক** করে ঢুকুন।

২. উপরের টুলবার থেকে **Select All** ক্লিক করুন — সব ফাইল নীল (হাইলাইট) হয়ে যাবে।

৩. উপরের টুলবার থেকে **Move** ক্লিক করুন।

৪. পপআপ বক্সে আগে থেকে যা লেখা আছে সেটি **মুছে** দিন, তারপর নিচের পাথটি **কপি-পেস্ট** করুন:
```
/home/cibdtamx/public_html
```

৫. **Move File(s)** ক্লিক করুন।

৬. যদি "Overwrite?" জিজ্ঞেস করে → **Yes / Overwrite** দিন।

> **ফলাফল:** ডিজাইন ফাইলগুলো `public_html`-এ চলে গেছে।

---

### অংশ খ: কোর (মূল) ফাইল সরানো

১. বাম পাশের প্যানেল থেকে আবার **`update`** ফোল্ডারে ক্লিক করে ফিরে আসুন।

২. কিবোর্ডে **`Ctrl`** চেপে ধরে (Mac হলে `Cmd`) নিচের **৫টি** আইটেম একে একে ক্লিক করে সিলেক্ট করুন:

| # | নাম | টাইপ |
|---|------|------|
| 1 | `.next` | 📁 ফোল্ডার |
| 2 | `content` | 📁 ফোল্ডার |
| 3 | `node_modules` | 📁 ফোল্ডার |
| 4 | `package.json` | 📄 ফাইল |
| 5 | `server.js` | 📄 ফাইল |

> [!WARNING]
> ❌ `public` ফোল্ডার সিলেক্ট **করবেন না** (সেটি আগেই সরানো হয়েছে)।
> ❌ `deploy_cpanel.zip` ফাইল সিলেক্ট **করবেন না**।

৩. উপরের টুলবার থেকে **Move** ক্লিক করুন।

৪. পপআপ বক্সে আগের লেখা **মুছে** দিন, তারপর নিচের পাথটি **কপি-পেস্ট** করুন:
```
/home/cibdtamx/cib_nextjs_app
```

৫. **Move File(s)** ক্লিক করুন।

> **ফলাফল:** মূল অ্যাপের ফাইলগুলো `cib_nextjs_app`-এ চলে গেছে।

## 🔄 ধাপ ৫ — সার্ভার রিস্টার্ট ও ভেরিফিকেশন

> **কেন:** সব ফাইল জায়গামতো আছে, কিন্তু সার্ভার এখনও পুরনো ফাইল দিয়ে চলছে। রিস্টার্ট দিলে সার্ভার নতুন ফাইলগুলো পড়তে শুরু করবে।

**করণীয়:**

১. cPanel-এর **হোম পেজে** ফিরে যান (বাম-উপরে cPanel লোগোতে ক্লিক করুন)।

২. সার্চ বারে লিখুন:
```
Node
```
এবং **Setup Node.js App** অপশনটিতে ক্লিক করুন।

৩. আপনার অ্যাপের তালিকায় `CIBDHK.COM` এর ডানপাশে থাকা **⟳ Restart** বাটনে ক্লিক করুন।

৪. কয়েক সেকেন্ড অপেক্ষা করুন — সবুজ সাকসেস মেসেজ আসবে।

### ✅ ফাইনাল ভেরিফিকেশন চেকলিস্ট

| # | চেক | কিভাবে করবেন |
|---|------|-------------|
| 1 | হোমপেজ লোড হচ্ছে | ব্রাউজারে `cibdhk.com` যান, `Ctrl + F5` (Mac: `Cmd + Shift + R`) চেপে হার্ড রিফ্রেশ দিন |
| 2 | ডিজাইন ঠিক দেখাচ্ছে | ছবি, ফন্ট, রঙ সব ঠিকমতো লোড হচ্ছে কি না চেক করুন |
| 3 | ফোন থেকেও দেখুন | মোবাইল ব্রাউজারে সাইটটি খুলে চেক করুন |
